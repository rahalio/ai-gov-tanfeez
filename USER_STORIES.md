# Tanfeez — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Delivery Unit / strategic management officer

- As a delivery officer, I want every initiative mapped to a Vision goal, so that orphan activity cannot hide under a programme brand.
- As a strategic management officer, I want automatic detection of duplication and contradiction across agencies, so that CEDA sees collisions before announcements.
- As a delivery lead, I want green status blocked when mandatory KPIs are missing, so that dashboards cannot lie by omission.

### Agency PMO lead

- As a PMO lead, I want to register initiatives with clear performance indicators from the NTP workshop format, so that my agency meets the Vision’s detailing standard.
- As a PMO lead, I want shared-service prerequisites visible on my critical path, so that I do not promise dates my dependencies cannot meet.
- As a PMO lead, I want to contest a contradiction flag with evidence, so that false conflicts can be cleared without politics alone.

### Performance management analyst

- As a performance analyst, I want versioned KPI definitions, so that year-on-year Effectiveness Index contributions remain comparable.
- As a performance analyst, I want dashboards that promote accountability without exposing confidential executive ratings to the public view.

### Budget / Qawam reviewer

- As a Qawam reviewer, I want spending-efficiency findings linked to the initiatives they affect, so that waste reduction changes delivery plans rather than dying in audit PDFs.
- As a budget officer, I want double-funded overlapping initiatives listed, so that Fiscal Balance actions have a queue.

### Decision Support Center analyst

- As a DSC analyst, I want a frozen evidence pack when a KPI breaches escalation thresholds, so that decision support is analytical rather than anecdotal.
- As a DSC analyst, I want sectoral strategy coverage checks, so that Vision components missing a proper sector strategy are visible.

### Platform administrator / transparency officer

- As a transparency officer, I want public and confidential projections of the same programme, so that we can publish progress without leaking protected data.
- As a platform administrator, I want phased onboarding of new executive programmes, so that continuous launch does not require downtime.
